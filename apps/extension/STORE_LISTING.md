## Full Description

Inspect, annotate, and give feedback on any live interface.

Mesurer runs directly where you build. Share feedback with your agents and your team.

Use Mesurer to inspect UI, understand layout and typography, annotate live interfaces, communicate visual changes, and capture precise context for your agents and team.

### Measure

- Measure element dimensions
- Add horizontal and vertical guides
- Use pixel rulers
- Inspect spacing, padding, and margins
- Compare distances between elements and guides

### Inspect

- Pick and copy colors
- Inspect typography
- Reveal interface structure with X-ray mode
- Understand layout and visual relationships

### Annotate

- Draw arrows and freehand pen strokes
- Add, edit, resize, and rotate text annotations
- Select and transform multiple annotations together

### Capture

- Capture your interface with Mesurer overlays included
- Copy screenshots instantly
- Share exactly what you see with your coding agent

### Built for visual precision

Mesurer gives you a precise visual layer directly inside the browser, without switching between tools.

Useful for design engineering, frontend development, visual QA, UI inspection, and agent-assisted development.

### Private by default

Mesurer runs locally in your browser. No account is required for the core experience.
